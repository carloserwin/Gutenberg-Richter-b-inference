# Gutenberg–Richter `b`-value inference

Reproducible R code accompanying the manuscript **“A unified probabilistic framework for Gutenberg–Richter `b`-value estimation and uncertainty quantification.”**

The project compares magnitude-based and magnitude-difference-based estimators, continuous and discrete formulations, and model-based, nonparametric and finite-sample confidence intervals. Monte Carlo experiments examine magnitude discretisation, uniform jittering and transient catalogue incompleteness. A real-data example studies the 2017 Tehuantepec earthquake sequence.

## Repository structure

All R scripts are intended to be placed in the repository root.

| File | Purpose |
| --- | --- |
| `1_easy_example.r` | Single-catalogue example of the estimators and confidence intervals. |
| `2_run_simulation.r` | Main Monte Carlo experiments for complete (Level 1) and transiently incomplete (Level 2) catalogues, with or without jittering. |
| `3_run_simulation_mags_based.r` | Level 2 experiments for magnitude-based estimators, estimating the completeness threshold by maximum curvature in each replicate. |
| `4_real_dataset.r` | Moving-window analysis and plots for the 2017 Tehuantepec sequence. |
| `extras_catalog_sim.r` | Catalogue generation and time-dependent detection functions. |
| `extras_estimators.r` | Estimators, interval constructions and supporting statistics. |
| `extras_simulation.r` | Monte Carlo evaluation routines. |
| `extras_plots.r` | Moving-window and plotting functions. |
| `DATA/` | Input catalogue for the real-data analysis (see below). |
| `TAB/` | CSV outputs created by the simulation scripts. |
| `GRAF/` | Figures generated by the real-data script. |

## Running the R scripts

Run the scripts **from the repository root directory** so that `my_dir <- "."` resolves the input scripts and output folders correctly. For example, in an R session with the repository as its working directory:

```r
source("1_easy_example.r")
```

The main experiments can be reproduced using:

```r
source("2_run_simulation.r")
source("3_run_simulation_mags_based.r")
```

In `2_run_simulation.r`, select the scenario using `lev` and `jitter`:

- `lev = 1`: complete ETAS–GR catalogues; `lev = 2`: catalogues subject to time-dependent detection.
- `jitter = 0`: analyze the original binned magnitudes; `jitter = 1`: apply uniform jittering for continuous procedures.
- `m = 10000`: number of Monte Carlo replications used for the manuscript tables.

The catalogue sizes are `c(20, 100, 300, 2000)` for Level 1 and `c(100, 190, 400, 2120)` for Level 2. **In Level 2 these are the sizes before applying the detection filter**, not the numbers of observed events.

The main simulation parameters are `b = 1`, `mc = 0`, magnitude bin width `bin = 0.1`, positive-difference threshold `dc = 0.2`, and maximum forward-search lag `ell = 10`. The scripts specify the remaining ETAS and detection parameters and the random seeds.

Simulation results are written as CSV files under `TAB/`. The main experiments use filenames of the form `RES_<level>_<n>_ALL.csv` and `RES_<level>_<n>_JITTER.csv`. The maximum-curvature experiments use `RES_MAG_<level>_<n>.csv`. Re-running the same configuration overwrites the corresponding output file.

### Estimated completeness threshold experiment

`3_run_simulation_mags_based.r` estimates a completeness threshold separately for each simulated observed catalogue and retains magnitudes above that threshold. Thus, the size of the full simulated catalogue, the size after time-dependent detection, and the **effective number retained after completeness filtering** are distinct quantities.

## Real-data analysis

The analysis script expects the input file:

```text
DATA/BDf2_tehuantepec_2017_100km.rds
```

The input must contain the magnitude column `Magnitud` and the local event time column `datetime_local`. It analyzes overlapping windows of 400 earthquakes advanced by 50 events, applying an event-level uniform jitter once to the full catalogue before constructing the windows. The principal figure is saved to `GRAF/b_graf.pdf`.

## Reproducibility notes

The reported Monte Carlo measurements are empirical interval coverage (TC), percentage mean absolute estimation error (PMAB), and mean confidence interval length (`bar_d`). The finite-sample intervals for `b`-positive and `b`-more-positive use a working independence assumption for retained differences; they need not be exact under the dependent joint distribution.

The scripts implement the methods and settings studied in the accompanying manuscript. For method definitions, assumptions and interpretation of the results, consult the paper.
